# PHANTOMS AI — Week 5

## First Neural Network with PyTorch

This repository contains my Week 5 neural-network work for PHANTOMS AI.

### What I built

A fully connected neural network for handwritten-digit classification using the MNIST dataset and PyTorch.

### Topics covered

- PyTorch fundamentals
- Tensors
- MNIST dataset
- DataLoader
- Training and testing datasets
- Fully connected neural networks
- Model training
- Loss and accuracy tracking
- Model evaluation
- Saving a trained model as `.pth`

### Result

The model was trained for 5 epochs and reached **97.50% training accuracy** in the recorded run.

Dataset split:

- 60,000 training samples
- 10,000 testing samples

### Tools

Python · PyTorch · torchvision · Matplotlib

This work builds the neural-network foundation needed to understand modern AI systems before moving deeper into machine learning security, AI Security, and LLM Red Teaming.
